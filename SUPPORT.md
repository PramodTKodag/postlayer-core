# Support

- **Questions and ideas:** use [GitHub Discussions](https://github.com/PramodTKodag/postlayer/discussions).
- **Bugs:** open an [issue](https://github.com/PramodTKodag/postlayer/issues/new/choose) with the steps to reproduce.
- **Security problems:** never a public issue. Follow [SECURITY.md](SECURITY.md).
- **Using it:** read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) first.

This is an unaudited open-source project maintained on a best-effort basis. There is no support contract and no response-time guarantee.
